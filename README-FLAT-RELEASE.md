# 简洁双入口生产布局（flat-production-86）

基线：0395c4b。只调整布局、路由恢复及入口；不修改 GitHubClient、服务端、上传/保存/改名/删除/批量提交实现。

## 入口迁移

| 原入口 | 新位置 |
| --- | --- |
| 总览、登录/连接后总览 | 默认图片资源；历史 overview/activity 原地恢复为 assets |
| 图片资源、JSON 库侧栏按钮 | sticky 顶部两主导航 |
| 仓库设置 | 右上角显式齿轮（主题及 GitHub 源码入口并列保留） |
| 侧栏当前仓库、连接状态、打开仓库 | 主导航下轻量身份行，鼠标/触摸/Enter/Space；设置中亦可打开当前仓库 |
| 切换/选择已有仓库 | 齿轮设置：真实仓库选择入口和手动配置表单 |
| 新建/改名/删除仓库 | 齿轮设置显式按钮；原确认及提交保护不变 |
| 用户身份 | 齿轮设置：原头像/登录账号 |
| 退出 GitHub | 齿轮设置显式退出按钮 |
| 清除此设备记住的 Token | 齿轮设置显式按钮（仅开启 Token 登录时显示） |
| 管理后台 | 齿轮设置显式按钮；保持原权限门槛及管理表单 |
| 搜索快捷键 | Cmd/Ctrl+K 聚焦当前页面真实搜索；移除原未绑定业务的重复全局搜索框 |
| JSON 库切换 | 保留真实切换弹窗，不引入原型模拟浮层；独立选库、删除和“新建 JSON 库”按钮 |
| 图片分组 | 保留真实分组条、新建、管理入口及上传中新增分组/选择分组 |
| 同步记录 | 没有可见导航或页面；内部同步/记录保留 |

库切换弹窗增加当前库焦点、Tab/Shift+Tab循环、Esc/外点击关闭、触发器焦点恢复和 aria-expanded 同步。排序/上传字段沿用原 Floating UI 真菜单，保持定位、滚动更新、外点击、Esc及键盘焦点恢复。

## 保留契约

- 图片资源模板字节不变；手机三列、桌面六列、正方形缩略图及 contain、22px 勾选内框/28px命中区、复制/选择嵌套操作不误开详情。
- JSON 引用仍是列表行，保留选中、多选、复制、删除、详情及键盘焦点；显式“复制 JSON 直链”，完整“新建 JSON 库”。320px 极窄屏库操作分两行以避免裁字；图片/引用区域不重画。
- 设置往返保留搜索、分组、图片选择和库引用选择；跨仓库读取仍按原业务清理选择。
- 原主题与按钮按压修复保留。登录34px控件、18px图标无常态阴影；Token focusin 光标代码字节不变。
- github.js、server.mjs、styles.css、console.css、popup.js 与基线SHA256完全一致；tests/flat-preservation.cjs 防护。
